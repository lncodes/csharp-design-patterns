# Builder Design Pattern

> Part of [**csharp-design-patterns**](../../README.md) · targets **.NET 10**

This project demonstrates the **Builder** design pattern in C#, with a classic GoF version (`Builder`, `Director`, concrete builders) and modern variants (fluent builder and generic builder).

## Quick start

```bash
git clone https://github.com/lncodes/csharp-design-patterns.git
cd csharp-design-patterns/creational/builder
dotnet build src
dotnet test test
```
