<h2 id="introduction">🌟 Introduction</h2>

This repository demonstrates the **Factory Method** design pattern in C#. Enemy factories (`GoblinEnemyFactory`, `OrcEnemyFactory`, `SlimeEnemyFactory`) create enemies through a common `EnemyFactory` abstraction.

<h2 id="installation">📦 Installation</h2>

1. Clone or download the project.
    ```bash
    git clone https://github.com/lncodes/csharp-design-patterns.git
    cd csharp-design-patterns/creational/factory-method
    ```

2. Open `src/FactoryMethod.sln` in Visual Studio or Rider.

> Targets **.NET 10** (set once in the collection's `Directory.Build.props`). You can also open `csharp-design-patterns.sln` at the repository root to get every project at once.

<h2 id="usage">🧑‍💻 Usage</h2>

- Build:
    ```bash
    dotnet build "src/FactoryMethod.sln"
    ```

- Run the unit tests:
    ```bash
    dotnet test "test"
    ```
