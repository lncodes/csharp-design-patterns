<h2 id="introduction">🌟 Introduction</h2>

This repository demonstrates the **Facade** design pattern in C#. A facade gives one simple entry point to an inventory subsystem (weapons, armor, skill books and player class data), shown as both a regular facade and a singleton facade.

<h2 id="installation">📦 Installation</h2>

1. Clone or download the project.
    ```bash
    git clone https://github.com/lncodes/csharp-design-patterns.git
    cd csharp-design-patterns/structural/facade
    ```

2. Open `src/Facade.sln` in Visual Studio or Rider.

> Targets **.NET 10** (set once in the collection's `Directory.Build.props`). You can also open `csharp-design-patterns.sln` at the repository root to get every project at once.

<h2 id="usage">🧑‍💻 Usage</h2>

- Build:
    ```bash
    dotnet build "src/Facade.sln"
    ```

- Run the unit tests:
    ```bash
    dotnet test "test"
    ```
